# v2 Etapa 4 — Equipo y Mi perfil: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sección Equipo para todos (con gestión para el admin), fotos de perfil guardadas en Firestore y el estado "inactiva" visible en toda la app.

**Architecture:** El perfil suma `photo` (JPEG 128×128 en data URL) protegido por reglas; la imagen se procesa en el navegador. `Avatar` muestra foto o inicial y el estado inactivo; `makePersonOf` le da a cada pantalla la foto y el estado del responsable. `TeamPage` reemplaza a `InvitePage` y reutiliza `updateMember` e invitaciones de la etapa 1.

**Tech Stack:** React 19, React Router 8, Firebase 12, Canvas + `createImageBitmap`, Vitest + RTL, emulador de Firestore.

**Spec:** `docs/specs/2026-10-09-v2-etapa4-equipo-design.md`

## Global Constraints

- Foto: `data:image/jpeg;base64,…`, 128×128, calidad 0.8, máximo 50 000 caracteres (reglas). Entrada aceptada: imagen de hasta 5 MB.
- Cada persona cambia solo su `displayName` y su `photo`; el admin cambia solo `role` y `active` de otras personas; nadie cambia su propio rol ni se desactiva.
- Textos: "Inactiva", "Tú", "Mi perfil", "+ Invitar", "N integrantes activos", "N tareas abiertas" / "1 tarea abierta" / "Sin tareas abiertas".
- Aviso al desactivar: `"{Nombre} tiene {N} tareas sin terminar. Seguirán a su nombre, marcado como inactiva; puedes reasignarlas desde Mis tareas."` (N = 1: "1 tarea sin terminar"); N = 0: `"¿Desactivar a {Nombre}? Ya no podrá entrar."`
- Producción no se toca; reglas solo a `matecode-tasks-dev`. Sin Firebase Storage.
- Cada tarea termina con `npm test`, `npm run build`, `npm run lint` (y `npm run test:rules` si toca reglas) en verde.
- Commits Conventional en español con trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

/** Cada persona cambia su propio nombre visible y su foto. */
export async function updateOwnProfile(
  db: Firestore,
  uid: string,
  patch: { displayName?: string; photo?: string | null },
): Promise<void> {
  const ref = doc(db, 'users', uid);
  await runTransaction(db, async (tx) => {
    const snap = await tx.get(ref);
    if (!snap.exists()) throw new Error('El usuario no existe.');
    const before = snap.data();
    const rev = before.rev + 1;
    const clean = { ...patch, ...(patch.displayName !== undefined && { displayName: patch.displayName.trim() }) };
    const after = { ...before, ...clean, rev };
    tx.set(ref, after);
    tx.set(
      auditRef(db, 'user', uid, rev),
      auditEntry({ type: 'user', id: uid, rev, action: 'update', actorId: uid, before, after }),
    );
  });
}

```ts
// src/features/team/avatarImage.ts
export const AVATAR_SIZE = 128;
const MAX_INPUT_BYTES = 5 * 1024 * 1024;

/** Error con un mensaje listo para mostrar. */
export class AvatarImageError extends Error {}

/** El cuadrado más grande centrado dentro de la imagen. */
export function squareCrop(width: number, height: number): { sx: number; sy: number; size: number } {
  const size = Math.min(width, height);
  return { sx: Math.floor((width - size) / 2), sy: Math.floor((height - size) / 2), size };
}

/**
 * Recorta la imagen en cuadrado y la reduce a 128×128 JPEG (unos 10 KB) en el navegador.
 * Así la foto entra en el perfil de Firestore sin usar Firebase Storage (que exige el plan pago).
 */
export async function imageToAvatar(file: File): Promise<string> {
  if (!file.type.startsWith('image/')) throw new AvatarImageError('Elige un archivo de imagen (JPG, PNG o WebP).');
  if (file.size > MAX_INPUT_BYTES) throw new AvatarImageError('La imagen pesa más de 5 MB. Elige una más liviana.');

  const bitmap = await createImageBitmap(file);
  const { sx, sy, size } = squareCrop(bitmap.width, bitmap.height);
  const canvas = document.createElement('canvas');
  canvas.width = AVATAR_SIZE;
  canvas.height = AVATAR_SIZE;
  const context = canvas.getContext('2d');
  if (!context) throw new AvatarImageError('Tu navegador no pudo procesar la imagen.');
  context.drawImage(bitmap, sx, sy, size, size, 0, 0, AVATAR_SIZE, AVATAR_SIZE);
  bitmap.close();
  return canvas.toDataURL('image/jpeg', 0.8);
}
```

export type Person = { name: string; photo: string | null; active: boolean };
export type PersonOf = (uid: string | null) => Person | null;

/** Datos para el avatar de una persona (foto y si está activa). */
export function makePersonOf(members: readonly UserProfile[]): PersonOf {
  const people = new Map(members.map((m) => [m.uid, { name: m.displayName, photo: m.photo ?? null, active: m.active }]));
  return (uid) => (uid ? people.get(uid) ?? null : null);
}

/** Tareas asignadas sin terminar, por persona. */
export function openTasksByMember(tasks: readonly Task[]): Map<string, number> {
  const counts = new Map<string, number>();
  for (const task of tasks) {
    if (task.assigneeId && task.status !== 'done') counts.set(task.assigneeId, (counts.get(task.assigneeId) ?? 0) + 1);
  }
  return counts;
}

/** Texto de confirmación al desactivar a alguien. */
export function deactivateMessage(name: string, openTasks: number): string {
  if (openTasks === 0) return `¿Desactivar a ${name}? Ya no podrá entrar.`;
  const tasks = openTasks === 1 ? '1 tarea sin terminar' : `${openTasks} tareas sin terminar`;
  return `${name} tiene ${tasks}. Seguirán a su nombre, marcado como inactiva; puedes reasignarlas desde Mis tareas.`;
}

}

type AvatarProps = { name: string; photo?: string | null; inactive?: boolean; size?: 'md' | 'lg' };

/** Foto o inicial. Decorativo: el nombre siempre está escrito al lado o en la etiqueta del botón. */

  return (

      {photo ? <img className={styles.photo} src={photo} alt="" /> : initial(name)}
    </span>
  );
}

      setSubmitting(false);

    try {
      await navigator.clipboard.writeText(link);
      setCopied(true);
    } catch {
      setError('No pudimos copiar el link. Selecciónalo y cópialo a mano.');
    }
  }

    const link = inviteLink(window.location.origin, created);

          <code className={styles.link}>{link}</code>
          <div className={styles.actions}>
            <Button variant="secondary" onClick={() => void copy(link)}>{copied ? 'Link copiado' : 'Copiar link'}</Button>
            <Button onClick={onClose}>Listo</Button>
          </div>
        </div>
      </Modal>
    );
  }

  return (

          <Button variant="ghost" onClick={onClose}>Cancelar</Button>

      </form>

  );

import { useEffect, useState } from 'react';
import { Alert } from '@/components/ui/Alert';
import { Button } from '@/components/ui/Button';
import { inviteLink } from '@/features/team/inviteLink';
import { InvitationError, revokeInvitation, subscribeToInvitations } from '@/services/team.service';
import { ROLE_LABEL } from '@/types/auth';
import type { Invitation } from '@/types/invitation';
import { formatRelative } from '@/utils/formatDate';
import styles from './PendingInvitations.module.css';

/** Invitaciones que todavía nadie aceptó (solo el admin las puede leer). */
export function PendingInvitations({ adminUid }: { adminUid: string }) {
  const [invitations, setInvitations] = useState<Invitation[]>([]);
  const [error, setError] = useState<string | null>(null);
  const [copied, setCopied] = useState<string | null>(null);

  useEffect(
    () =>
      subscribeToInvitations(setInvitations, (err) => {
        console.error('Error al leer invitaciones:', err);
        setError('No pudimos cargar las invitaciones.');
      }),
    [],
  );

  const pending = invitations.filter((inv) => inv.status === 'pending');

  async function copy(email: string) {
    try {
      await navigator.clipboard.writeText(inviteLink(window.location.origin, email));
      setCopied(email);
    } catch {
      setError('No pudimos copiar el link. Selecciónalo y cópialo a mano.');
    }
  }

  async function revoke(email: string) {
    setError(null);
    try {
      await revokeInvitation(adminUid, email);
    } catch (err) {
      console.error('Error al cancelar la invitación:', err);
      setError(err instanceof InvitationError ? err.message : 'No pudimos cancelar la invitación.');
    }
  }

  return (
    <section aria-labelledby="invitations-title" className={styles.section}>
      <h2 id="invitations-title" className={styles.title}>Invitaciones pendientes</h2>
      {error && <Alert kind="error">{error}</Alert>}
      {pending.length === 0 ? (
        <p className={styles.empty}>No hay invitaciones pendientes.</p>
      ) : (
        <ul className={styles.list}>
          {pending.map((inv) => (
            <li key={inv.email} className={styles.item}>
              <div className={styles.body}>
                <span className={styles.email}>{inv.email}</span>
                <span className={styles.meta}>{ROLE_LABEL[inv.role]} · invitada {formatRelative(inv.createdAt)}</span>
              </div>
              <div className={styles.actions}>
                <Button size="sm" variant="ghost" onClick={() => void copy(inv.email)}>
                  {copied === inv.email ? 'Link copiado' : 'Copiar link'}
                </Button>
                <Button size="sm" variant="ghost" onClick={() => void revoke(inv.email)}>Cancelar</Button>
              </div>
            </li>
          ))}
        </ul>
      )}
    </section>
  );
}

export function TeamPage() {
  const { profile } = useAuth();
  // RequireAccess garantiza un perfil activo.
  return <TeamView me={profile as UserProfile} />;
}

function TeamView({ me }: { me: UserProfile }) {
  const isAdmin = can(me, 'team:manage');
  const members = useTeamMembers();
  const { tasks } = useTasks(me.uid);
  const [inviting, setInviting] = useState(false);
  const [toast, setToast] = useState<ToastMessage | null>(null);
  const dismissToast = useCallback(() => setToast(null), []);

  const openTasks = openTasksByMember(tasks);
  const sorted = [...members].sort(
    (a, b) => Number(b.active) - Number(a.active) || a.displayName.localeCompare(b.displayName),
  );
  const activeCount = members.filter((m) => m.active).length;

  async function change(member: UserProfile, patch: { role?: Role; active?: boolean }, message: string) {
    try {
      await updateMember(me.uid, member.uid, patch);
      setToast({ kind: 'success', message });
    } catch (err) {
      console.error('Error al actualizar integrante:', err);
      setToast({ kind: 'error', message: 'No pudimos guardar el cambio. Inténtalo de nuevo.' });
    }
  }

  return (
    <>
      <PageHeader
        title="Equipo"
        subtitle={`${activeCount} ${activeCount === 1 ? 'integrante activo' : 'integrantes activos'}`}
        actions={isAdmin && <Button size="sm" onClick={() => setInviting(true)}>+ Invitar</Button>}
      />
      <main className={styles.page}>
        <section aria-labelledby="members-title" className={styles.section}>
          <h2 id="members-title" className={styles.title}>Integrantes</h2>
          <ul className={styles.list}>
            {sorted.map((member) => (
              <MemberRow
                key={member.uid}
                member={member}
                isMe={member.uid === me.uid}
                canManage={isAdmin && member.uid !== me.uid}
                openTasks={openTasks.get(member.uid) ?? 0}
                onRoleChange={(role) => void change(member, { role }, `Rol de ${member.displayName} actualizado.`)}
                onActiveChange={(active) =>
                  void change(member, { active }, `Acceso ${active ? 'reactivado' : 'desactivado'} para ${member.displayName}.`)
                }
              />
            ))}
          </ul>
        </section>
        {isAdmin && <PendingInvitations adminUid={me.uid} />}
      </main>
      {inviting && <InviteDialog adminUid={me.uid} onClose={() => setInviting(false)} />}
      {toast && <Toast toast={toast} onDismiss={dismissToast} />}
    </>
  );
}

```tsx
// src/components/team/ProfileDialog.tsx
import { useState, type ChangeEvent, type FormEvent } from 'react';
import { Avatar } from '@/components/layout/Avatar';
import { Alert } from '@/components/ui/Alert';
import { Button } from '@/components/ui/Button';
import { Field, fieldInputClass } from '@/components/ui/Field';
import { Modal } from '@/components/ui/Modal';
import { AvatarImageError, imageToAvatar } from '@/features/team/avatarImage';
import { updateOwnProfile } from '@/services/team.service';
import { ROLE_LABEL, type UserProfile } from '@/types/auth';
import styles from './ProfileDialog.module.css';

/** Foto y nombre de la persona que usa la app (el rol y el email no se cambian acá). */
export function ProfileDialog({ profile, onClose }: { profile: UserProfile; onClose: () => void }) {
  const [name, setName] = useState(profile.displayName);
  const [photo, setPhoto] = useState<string | null>(profile.photo ?? null);
  const [error, setError] = useState<string | null>(null);
  const [saving, setSaving] = useState(false);

  async function pickPhoto(event: ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    event.target.value = ''; // permite volver a elegir el mismo archivo
    if (!file) return;
    setError(null);
    try {
      setPhoto(await imageToAvatar(file));
    } catch (err) {
      if (!(err instanceof AvatarImageError)) console.error('Error al procesar la foto:', err);
      setError(err instanceof AvatarImageError ? err.message : 'No pudimos leer la imagen. Prueba con otra.');
    }
  }

  async function save(event: FormEvent) {
    event.preventDefault();
    const displayName = name.trim();
    if (!displayName) {
      setError('Ingresa tu nombre.');
      return;
    }
    setSaving(true);
    try {
      await updateOwnProfile(profile.uid, { displayName, photo });
      onClose();
    } catch (err) {
      console.error('Error al guardar el perfil:', err);
      setError('No pudimos guardar tu perfil. Inténtalo de nuevo.');
      setSaving(false);
    }
  }

  return (
    <Modal title="Mi perfil" onClose={onClose}>
      <form className={styles.form} onSubmit={save} noValidate>
        {error && <Alert kind="error">{error}</Alert>}
        <div className={styles.photoRow}>
          <Avatar name={name} photo={photo} size="lg" />
          <div className={styles.photoActions}>
            <label className={styles.upload}>
              Subir foto
              <input type="file" accept="image/jpeg,image/png,image/webp" className="visually-hidden" onChange={(e) => void pickPhoto(e)} />
            </label>
            {photo && <Button size="sm" variant="ghost" onClick={() => setPhoto(null)}>Quitar foto</Button>}
          </div>
        </div>
        <Field id="profile-name" label="Nombre">
          <input id="profile-name" className={fieldInputClass} value={name} maxLength={80} onChange={(e) => setName(e.target.value)} />
        </Field>
        <p className={styles.meta}>{profile.email} · {ROLE_LABEL[profile.role]}</p>
        <div className={styles.actions}>
          <Button variant="ghost" onClick={onClose}>Cancelar</Button>
          <Button type="submit" loading={saving}>Guardar</Button>
        </div>
      </form>
    </Modal>
  );
}
```
