# Etapa 10B v2 — Rediseño: Proyectos — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lista de proyectos y página de proyecto como las maquetas `proyectos.html` y `proyecto-pagina.html`.

**Architecture:** `ProjectCard` se rehace (sin "A cargo", con fila de íconos de datos reales); `ProjectsPage` usa `PageHeader` con descripción, `ViewTabs` con conteos y un buscador; el encabezado de `ProjectPage` pasa a "← Proyectos", nombre con su color, descripción, acciones y una fila de datos (Fechas, Avance, Personas del proyecto). `ShareProjectDialog` toma el estilo de la maqueta (rol debajo del nombre).

**Tech Stack:** React 19 + TS, CSS Modules + tokens, lucide-react, Vitest + RTL.

**Spec:** `docs/specs/2026-10-16-v2-etapa10-rediseno-design.md` (parte 10B).

## Global Constraints

- Sin "A cargo" en las tarjetas; el responsable va primero en las caras.
- Pie de la tarjeta con íconos: 📅 fecha de fin (roja + chip "Atrasado" si corresponde), ☑ "hechas/total" (Lector/Invitado: "N abiertas"), 👥 cantidad de personas. Solo datos reales.
- "Avance" con % y barra del color del proyecto (Lector/Invitado: "N tareas abiertas", sin barra).
- Proyectos: descripción "Fechas, avance y quiénes trabajan en cada uno."; pestañas "Activos N · Archivados N"; buscador "Buscar proyecto…" (por nombre y descripción, sin tildes).
- Página del proyecto: fila de datos con títulos chicos "Fechas", "Avance", "Personas del proyecto".
- Sin hex en componentes; contraste ≥ 4.5:1; `npm test`, `npm run build`, `npm run lint` antes de cada commit; un commit por tarea con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
